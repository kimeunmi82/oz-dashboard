# 호흡기 질환 진료비 격차 모니터링 대시보드

식약처 보건의료 분석 담당자용. 병원(종별·권역)별 진료비 격차를 정기적으로 확인하고, 호흡기 질환(J코드)을 깊게 분석한다.
데이터: Google Sheet (오즈코딩 헬스케어 SQL 3기 실습 데이터, 2024-01 ~ 2025-12)

## 실행
```bash
python3 build.py                  # 시트 다운로드 → 검증 → site/data/*.json
python3 -m http.server -d site    # http://localhost:8000
```

## 구조
`build.py`가 data/*.csv에서 지표 7개(kpi, cls_summary, dx_cls, region, monthly, inst_outliers, rx_class)를 집계해 site/data/*.json으로 쓰고, site/(index.html, style.css, app.js, vendor/d3.min.js)가 읽어 그립니다. `.claude/launch.json`은 미리보기 서버 설정입니다.

## 배포 (GitHub Pages)
`main`에 push하면 `.github/workflows/deploy.yml`이 시트를 받아 `build.py`로 집계한 뒤 `site/`를 배포합니다. 매월 5일에도 자동으로 다시 만듭니다. 원본 CSV는 저장소에 올리지 않고(.gitignore), 배포되는 것은 집계된 JSON뿐입니다.
- 수동 갱신: GitHub 저장소 Actions 탭에서 "Deploy dashboard" → Run workflow
- 주의: Pages 주소는 공개입니다. 실제 청구 데이터로 바꾸기 전에 배포 방식을 다시 정해야 합니다

## 규칙
1. 지표 하나 = JSON 하나 (build.py 함수 → site/data/<지표>.json)
2. 브라우저는 JSON만 읽는다 (raw CSV 금지)
3. 이름 통일: 함수 x() → x.json → 차트 x
4. build.py는 표준 라이브러리만. 새 의존성은 결정 로그에 기록
5. 분리 기준: build.py/app.js 300줄 초과, 화면 2개 이상, README 과다 → 그때만 폴더 분리

## 인터뷰 결과 (2026-10-21)
- **목적/사용자**: 식약처 보건의료 분석 담당자. "병원별 진료비 차이가 크다"는 이야기를 데이터로 주기 확인. 팀·상사에게 공유
- **분석 범위**: 호흡기 질환 중심(J코드). 감염병 A/B코드는 1,234건뿐이라 호흡기 감염 중심으로만 포함
- **비교 단위**: 종별(상급종합/종합/병원/의원) + 권역·시도. 기관 이름 없음 → 익명 기관 ID(`yid`) 기준
- **보정**: 환자 특성(연령대·성별·보험료 5분위) 보정 후 비교
- **대표 지표**: 중앙값 + P25/P75 범위 (이상치 때문에 평균 단독 사용 금지)
- **입원/외래**: 외래 중심, 입원은 별도 패널로 표시 (호흡기는 거의 외래)
- **처방(claim_rx)**: 포함 — 상병별 주성분, 처방액, 항생제 등 (`drug_ingredient`와 조인)
- **사용 방식**: 정기 모니터링(월 단위 갱신)
- **최소 표본**: 숨기지 않고 표본 수(n)를 함께 표시
- **배포**: 미정. 우선 로컬에서 완성, 이후 웹 배포 검토
- **갱신 방식**: 미정. 현재는 같은 시트를 다시 받는 방식

### 프로토타입 검토 후 확정 (2026-10-21)
- 화면 구성 그대로 확정 (추가·삭제 없음)
- 상병 구분은 현재 방식 유지: 주요 상병 5개(J209, J304, J00, J029, J039) 개별 표시
- 기관 경고 기준: 종별 중앙값 대비 1.5배 이상 (`build.py`의 `FLAG_RATIO`), 기관 순위는 8건 이상만 (`MIN_N`)

### 월별 비교 기준 (확정)
- 비교 지표: 호흡기 외래 청구 건수
- 기준: 전년 동월 대비가 기본, 전월 대비는 참고(계절 변동이 섞임). 2024년은 전년 값이 없어 비교 불가
- 경고: 기준 대비 ±10% 이상 (`build.py`의 `CHANGE_FLAG`), 화면에 표시되는 반올림 값으로 판정
- 근거: 2025-10→11월 전월 대비는 +51%, +53%지만 전년 동월 대비는 -2%, -1%로 계절 변동이었음

### 항생제 판정 (확정)
- 규칙(`build.py`의 `ABX_CLASSES`, `NON_ABX_NAME`): 약효분류 611–615, 618, 619, 621 중 성분명이 항바이러스·항진균(vir, conazole, fungin, amphotericin 등)이 아닌 것. 616(항진균·항결핵), 617(항암 항생물질)은 제외
- 이유: 약효분류 618에 항생제(amoxicillin)와 항바이러스제(acyclovir)가 섞여 있어 분류번호만으로는 부정확. 이전에 붙였던 "기타 화학요법제" 명칭은 오류여서 성분명 표시로 교체
- 데이터 한계: 호흡기 외래 처방에는 성분이 5종뿐이고 항생제는 amoxicillin 하나. 항생제 처방률은 38.5%이며 종별(37.9~40.4%), 상병별(36.8~38.4%) 모두 거의 동일. 알레르기비염(J304)도 36.8%라 실제 처방 패턴이 아니라 실습 데이터의 균일성으로 보임. 항생제 지표는 실제 데이터에서 의미가 생김
